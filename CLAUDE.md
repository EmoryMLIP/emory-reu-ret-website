## Project Overview

This is the source repository for the Emory REU/RET Computational Mathematics for Data Science website (www.math.emory.edu/site/cmds-reuret). The site is built using Hugo static site generator with the Wowchemy Research Group template and deployed to the Emory Math/CS server.

## Development Commands

### Local Development
```bash
# Install Hugo (required for development)
# On macOS: brew install hugo
# Version used in production: 0.80.0 (see netlify.toml)

# Serve site locally with live reload
hugo server

# Serve with future-dated content visible
hugo server --buildFuture

# Build site for production
hugo --gc --minify

# Build with future-dated content
hugo --gc --minify --buildFuture
```

### Publishing
The `publish.sh` script uploads the built site to the Math/CS server. This requires:
- SSH access to lab0z.mathcs.emory.edu as lruthot
- The site must be built first (generates `public/` directory)
- Only Lars can perform the final deployment step

```bash
# Build and publish (requires proper SSH credentials)
hugo --gc --minify
./publish.sh
```

## Architecture

### Content Organization

The site follows Hugo's standard structure with three primary areas for regular updates:

**1. Authors (`content/authors/`)**
- Each person has a subdirectory (named by username)
- Contains `_index.md` with frontmatter (YAML between `---` markers) defining:
  - Personal info (name, role, bio, interests, education)
  - Organizations/affiliations
  - Social links (email, Twitter, Google Scholar, GitHub, ORCID, etc.)
  - `user_groups` field determines where they appear (Mentors, Students, Teachers, etc.)
- Include profile photo as `avatar.jpg` or `avatar.png` in same directory

**2. Projects (`content/projects/`)**
- Named by year and topic (e.g., `2022-ozone`, `2023-fast-and-fair`)
- Each contains `index.md` with frontmatter:
  - `title`, `date`, `summary`, `tags`, `authors`
  - `draft: true/false` controls visibility
  - `featured: true/false` for homepage display
  - `weight` for ordering
- Can include media files (images, PDFs, videos) in project directory

**3. Summer Cohorts (`content/summer2021/`, `summer2022/`, etc.)**
- Each year has dedicated directory with:
  - `cohort.md` - participant information
  - `dates.md` - program timeline
  - `projects.md` - links to that year's projects
  - `theme.md` - visual theme settings

**4. Home Page (`content/home/`)**
- Widget-based homepage using markdown files:
  - `welcome.md` - main welcome text
  - `featured.md` - featured projects
  - `news.md` - recent updates
  - `contact.md` - contact information
  - `funding.md` - acknowledgements
- Each widget is a separate file with frontmatter controlling display

### Configuration

**Hugo Config (`config/_default/`)**
- `config.yaml` - main Hugo settings (title, baseURL, modules, taxonomies)
- `params.yaml` - Wowchemy theme parameters (appearance, SEO, features)
- `menus.yaml` - navigation menu structure
- `languages.yaml` - localization settings

The site uses:
- Hugo version 0.80.0 (production)
- Wowchemy/Hugo themes v5 modules
- Go modules for dependency management (see `go.mod`)

### Static Assets

**`static/` directory** - Files served directly without processing:
- `static/media/` or `static/img/` - Images (compress before adding!)
- Other static files (PDFs, etc.)

**`assets/` directory** - Theme assets (stylesheets, images)

**`data/` directory** - Data files for themes and fonts

### Generated Directories (DO NOT COMMIT)

- `public/` - Built site (generated by `hugo` command)
- `resources/` - Hugo cached resources

These are gitignored and should never be committed.

## Key Workflows

### Adding a New Person

1. Copy an existing author directory that matches the role
2. Rename to new username (should match `authors` field in frontmatter)
3. Update `_index.md` with person's information
4. Add profile photo as `avatar.jpg` or `avatar.png`
5. Set correct `user_groups` (Mentors, Students, Teachers, etc.)

### Adding a New Project

1. Create directory in `content/projects/` named `YEAR-topic`
2. Create `index.md` with frontmatter (copy from existing project)
3. Set `draft: false` when ready to publish
4. Add to appropriate summer cohort's `projects.md`
5. Set `featured: true` if it should appear on homepage

### Updating Summer Cohort

1. Create new `content/summerYYYY/` directory
2. Copy structure from previous year
3. Update `cohort.md`, `dates.md`, `projects.md`
4. Link projects using tags: `tags: ["Summer YYYY"]`

### Editing Homepage Content

Edit markdown files in `content/home/`:
- `welcome.md` - main introductory text
- Other widgets control what appears on homepage

## Important Notes

- **Images**: Compress images before adding to reduce file size
- **Draft Content**: Set `draft: false` in frontmatter to make content visible
- **Taxonomies**: Use `tags`, `authors`, and `categories` to connect content
- **Permalinks**: Authors, tags, categories have custom URL structures (see `config.yaml`)
- **Math Support**: Enabled via Wowchemy features (can use LaTeX in markdown). **IMPORTANT**: Escape underscores as `\_` in LaTeX to prevent markdown from interpreting them as italics. This is critical when multiple math expressions with subscripts appear on the same line or in display equations with many subscripts. For example, use `$\mathbf{A}\_{\text{opt}}^r$` instead of `$\mathbf{A}_{\text{opt}}^r$`
- **Deployment**: Final publishing to production requires SSH access as lruthot
- **Theme**: Based on Wowchemy Research Group template - avoid modifying theme files directly

## Content Format

All content files use:
- **Markdown** for body text
- **YAML frontmatter** (between `---` markers) for metadata
- **Hugo shortcodes** for special features (see Wowchemy docs)
